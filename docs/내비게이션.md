# 내비게이션 시스템

## 트리거 키워드

| 키워드 | 예시 |
|--------|------|
| `길찾기`, `길 찾기` | `강남역 길찾기` |
| `내비`, `네비` | `판교 내비` |
| `카카오맵`, `카카오 맵` | `을지로 카카오맵` |
| `티맵`, `tmap` | `을지로 티맵` |
| `네이버지도`, `네이버 지도` | `종로 네이버지도` |

## 앱 선택 다이얼로그

내비 키워드 감지 시 앱 선택 시트 표시 (모두 앱 우선, 웹 폴백):

| 앱 | 앱 스킴 | 웹 폴백 |
|----|---------|---------|
| 카카오맵 | `kakaomap://search?q=목적지` | `https://map.kakao.com/link/search/목적지` |
| 카카오내비 | `kakaomap://search?q=목적지` | `https://map.kakao.com/link/search/목적지` |
| Tmap | `tmap://search?name=목적지` | `http://maps.apple.com/?q=목적지` |
| 네이버맵 | `nmap://search?query=목적지&appname=bundleID` | `https://map.naver.com/v5/search/목적지` |
