# 검색 시스템

## 검색 서비스 및 URL 정책

### 앱 우선 실행 (항상)
앱이 설치되어 있으면 앱에서 열고, 없으면 웹 브라우저로 폴백.

| SearchType | 앱 스킴 | 웹 폴백 |
|-----------|---------|---------|
| `youtube` | `youtube://www.youtube.com/results?search_query=` | `https://www.youtube.com/results?search_query=` |
| `netflix` | `nflx://www.netflix.com/search?q=` | `https://www.netflix.com/search?q=` |
| `shoppingNaver` | `naversearchapp://inappbrowser?url={인코딩된 쇼핑URL}` | `https://msearch.shopping.naver.com/search/all?query=` |
| `coupang` | `coupang://search?q=` | `https://www.coupang.com/np/search?q=` |
| `appstore` | `itms-apps://search.itunes.apple.com/...` | — |

### 검색엔진 (앱/웹 설정 적용)
`preferAppForSearch` 설정에 따라 앱 또는 `SFSafariViewController`(인앱 브라우저)로 전환.

| SearchType | 앱 우선 (켜짐) | 웹 브라우저 (꺼짐) |
|-----------|-------------|-----------------|
| `naver` | `naversearchapp://search?query=` → 웹 폴백 | `SFSafariViewController` |
| `google` | `UIApplication.open` (Universal Link → 구글 앱) | `SFSafariViewController` |
| `perplexity` | `UIApplication.open` (Universal Link → 퍼플렉시티 앱) | `SFSafariViewController` |

### 사전
네이버 사전 3종류. 숏컷 버튼 및 별칭 등록 가능.
**모든 사전 검색은 `SFSafariViewController`(인앱 사파리)로 열림.**

| SearchType | URL | 비고 |
|-----------|-----|------|
| `dictionaryEnglish` | `https://en.dict.naver.com/#/search?query=` | 영어사전, 인앱 사파리 |
| `dictionaryKorean` | `https://dict.naver.com/dict.search?query={검색어}&from=tsearch` | 국어사전, 인앱 사파리 |
| `dictionaryHanja` | `https://hanja.dict.naver.com/#/search?query={검색어}&range=all` | 한자사전, 인앱 사파리 |
| `dictionary` | `https://english.dict.naver.com/english-dictionary/#/search?query=` | 영영사전, 자연어 트리거 전용 |

**자동 언어 감지** (`사전` 키워드 사용 시):
- 영어 문자 우세 → 영어사전
- 한자(CJK Unified, U+4E00~U+9FFF) 포함 → 한자사전
- 그 외(한국어 등) → 국어사전

## 받아쓰기 (Dictation)

입력창 마이크 버튼(🎤)으로 음성 입력 가능.
- `SFSpeechRecognizer` (한국어, `ko-KR`)
- `AVAudioEngine`으로 실시간 음성 → 텍스트 변환
- 부분 결과 실시간 반영 (`shouldReportPartialResults`)
- 녹음 중 빨간 맥동 애니메이션
- 권한: `NSSpeechRecognitionUsageDescription`, `NSMicrophoneUsageDescription`

## 쿼리 정제 (인텐트별 분리)

기존 `cleanText`의 전역 토큰 제거 방식을 폐기하고, 인텐트별 전용 클리닝 적용:

| 함수 | 대상 | 제거 토큰 | 보존 |
|------|------|----------|------|
| `cleanForMessage` | 메시지 | 에게, 한테, 문자, 보내줘, 카톡 등 | 일반 단어 |
| `cleanForNavigation` | 네비 | 으로, 해줘 등 | "에서" 보존 |
| `cleanForSearch` | 웹검색 | 없음 (특수문자만 정리) | 쿼리 완전 보존 |

**숏컷 버튼은 입력 그대로 전달** (정제 안 함).

## 자연어 파서 키워드 (SmartParser)

### 서비스 키워드 → 바로 실행
| 키워드 | 서비스 |
|--------|--------|
| `유튜브` | YouTube |
| `넷플릭스` | Netflix |
| `앱스토어` | App Store |
| `사전` | 자동 감지 (영어/국어/한자사전) |
| `영화`, `tmdb` | TMDB |
| `chatgpt`, `gpt`, `체티지피티` | ChatGPT |
| `gemini`, `제미나이`, `제미니` | Gemini |
| `claude`, `클로드` | Claude |
| `perplexity`, `퍼플렉시티` | Perplexity |
| `grok`, `그록` | Grok |

### AI 트리거 → 기본 AI 서비스 (설정 연동)
어근 접두사 매칭으로 오타/띄어쓰기/존댓말 변형 자동 흡수:
| 어근 | 예시 (자동 매칭) |
|------|------|
| `알려` | 알려줘, 알려 줘, 알려조, 알려주세요 |
| `물어` | 물어봐, 물어 봐, 물어바 |
| `요약해` | 요약해줘, 요약해조, 요약해주세요 |
| `번역해` | 번역해줘, 번역해 줘 |
| `정리해` | 정리해줘, 정리해조 |
| `설명해` | 설명해줘, 설명해 줘 |
| `분석해` | 분석해줘, 분석해조 |
| `찾아` | 찾아줘, 찾아 줘 |
| `질문` | 정확 일치 |

### 빈 쿼리 → 앱 열기 폴백
키워드만 입력 시(검색어 없음) 해당 앱을 직접 실행:
- `유튜브` → YouTube 앱 열기
- `앱스토어` → App Store 열기
- `chatgpt` → ChatGPT 앱 열기
- 앱 미설치 시 웹 폴백

### 일정 vs 웹검색 충돌 가드
일정으로 파싱되더라도 제목에 웹검색 키워드(`날씨`, `환율`, `주가`, `뉴스`, `검색`, `맛집`)가 포함되면 웹검색으로 오버라이드.
- 예: `내일 서울 날씨` → 웹검색 (일정 아님)

### 입력 전처리 (normalizeInput)
모든 파싱 전에 자동 적용:
- 전각→반각 변환 (Ａ→A, ：→:)
- 반복 공백 통일
- Unicode 정규화 (NFC)

### A→B 경로 탐색 (Route Navigation)
출발지와 목적지를 지정하여 지도앱에서 길찾기 실행:

**자동 감지 (제안카드)**
- `광화문에서 신창시장` → 길안내 카드 표시 (A → B)
- `서울역부터 인천공항` → 동일
- `판교역에서 강남역으로` → "으로" 자동 제거

**수동 숙컷 (출발지 목적지 분리)**
- `광화문 신창시장` + **네이버 경로** 버튼 → 고백 기준 분리

**지원 앱**: 네이버맵, 카카오맵

**좌표 변환**: CLGeocoder (한국 로케일) + MKLocalSearch (POI 폴백)
장소명 → 좌표(lat/lng) 변환 후 지도앱 route URL 스킴으로 전달.

### 전화 / 이메일 키워드 자동 채널
연락처 매칭 + 키워드 감지 → 시트 스킵하고 바로 실행:
| 키워드 | 동작 |
|--------|------|
| `전화해`, `전화 걸어`, `전화줘`, `통화` | `tel://` 전화 바로 연결 |
| `이메일`, `메일 보내` | `mailto:` 이메일 작성 |

키워드 없으면 채널 선택 시트 표시 (전화/문자/이메일/공유).

### 기본 AI 서비스
`선택 시트 표시` (기본) / `ChatGPT` / `Gemini` / `Claude` / `Perplexity` / `Grok`

### 앱 우선 실행
켜짐 (기본): 네이버·구글·퍼플렉시티 검색 시 앱에서 열기
꺼짐: `SFSafariViewController`(인앱 브라우저)로 열기

## URL Scheme

```
anyquick://search?q=검색어                    → 텍스트 프리필
anyquick://search?q=검색어&type=naver         → 바로 Naver 검색 실행
anyquick://search?q=검색어&type=youtube       → 바로 YouTube 검색 실행
```

## 앱 바로가기 (App Shortcuts)

사용자가 등록한 앱을 숏컷 그리드에서 바로 실행.

- 환경설정 또는 숏컷 그리드의 `앱열기` → `앱 추가` 에서 등록
- 앱 이름, URL Scheme, 아이콘(SF Symbol) 지정
- UserDefaults에 JSON으로 저장 (`appShortcuts` 키)
