# AnyQuick 아키텍처

## 실행 흐름

```
사용자 입력
    │
    ▼
① 커맨드 별칭 매칭 (OmniViewModel.matchAlias)
    │── 매칭 → 해당 서비스로 바로 검색 실행
    │
    ▼
② 자연어 파서 (SmartParser.parse)
    │── .addSchedule    → 일정/미리알림 등록
    │── .sendMessage    → 메시지 발송
    │── .navigation     → 내비 앱 선택 시트
    │── .webSearch      → AI 키워드 → AI 선택 시트 / 서비스 키워드 → 바로 실행
    │
    ▼
③ .unknown (미인식)
    │── cleanSearchQuery()로 명령어 제거 ("검색", "찾아줘" 등)
    │── 기본 검색 엔진 설정됨 → 바로 검색
    │── 미설정 → 웹검색 서비스 선택 시트
```

## 제안 카드 (Suggestion Card)

입력 시 실시간으로 카드가 표시됩니다:

| 조건 | 카드 | 색상 |
|------|------|------|
| 별칭 매칭 | `🔗 별칭: {keyword}` | 인디고 |
| 연락처 매칭 | `👤 연락처 선택` | 민트 |
| 미인식 텍스트 | `🔍 웹 검색` | 보라 |
| 일정 파싱 | `📅 일정 등록` | 주황 |
| 메시지 파싱 | `💬 메시지 발송` | 초록 |
| 길안내 파싱 | `🚗 길안내 시작` | 파랑 |
| 웹검색 파싱 | `🔍 웹 검색` | 보라 |

## 파일 구조

| 파일 | 역할 |
|------|------|
| `SmartIntent.swift` | Intent 열거형, SearchType, CommandAlias 모델 |
| `SmartParser.swift` | 자연어 입력 → SmartIntent 파싱 |
| `ActionManager.swift` | Intent 실행, 설정 CRUD, URL 스킴 처리, SFSafariViewController |
| `OmniViewModel.swift` | UI 상태 관리, 별칭 매칭, 검색 기록, 쿼리 정제, 받아쓰기 |
| `ContentView.swift` | SwiftUI UI (입력, 제안 카드, 숏컷, 설정) |

## 데이터 저장 (UserDefaults)

| 키 | 타입 | 설명 |
|----|------|------|
| `preferredEventCalendarIdentifier` | String? | 선호 캘린더 |
| `preferredReminderListIdentifier` | String? | 선호 미리알림 목록 |
| `defaultSearchEngine` | String? | 기본 검색 엔진 (SearchType.rawValue) |
| `defaultAIService` | String? | 기본 AI 서비스 |
| `searchHistory` | [String] | 최근 검색어 (최대 10개) |
| `commandAliases` | Data (JSON) | 커맨드 별칭 배열 |
| `preferAppForSearch` | Bool | 검색엔진 앱 우선 실행 (기본: true) |

## 입력 방식

| 방식 | 설명 |
|------|------|
| 키보드 | 직접 타이핑 |
| 클립보드 | 복사된 텍스트 붙여넣기 |
| 받아쓰기 | 마이크 버튼 → `SFSpeechRecognizer` 한국어 음성 인식 |
