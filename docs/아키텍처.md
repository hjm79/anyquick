# AnyQuick 아키텍처

## 실행 흐름

```
사용자 입력
    │
    ▼
⓪ 입력 전처리 (normalizeInput: 전각→반각, 공백통일)
    │
    ▼
① 커맨드 별칭 매칭 (OmniViewModel.matchAlias)
    │── 매칭 → 해당 서비스로 바로 검색 실행
    │
    ▼
② 자연어 파서 (SmartParser.parse)
    │── .addSchedule    → 일정/미리알림 등록 (날씨/환율/뉴스 포함 시 웹검색 오버라이드)
    │── .sendMessage    → 전화/이메일 키워드 → 바로 실행 | 일반 → 채널 선택 시트
    │── .navigation     → 네비 앱 선택 시트 (A→B: 네이버맵/카카오맵만 | 단일: 전체)
    │── .webSearch      → AI 키워드 → AI 선택 시트 / 서비스 키워드 → 바로 실행
    │── .openApp        → 빈 쿼리 시 해당 앱 직접 실행 ("유튜브" → YouTube 앱 열기)
    │
    ▼
③ .unknown (미인식)
    │── cleanSearchQuery()로 명령어 제거 ("검색", "찾아줘" 등)
    │── 기본 검색 엔진 설정됨 → 바로 검색
    │── 미설정 → 웹검색 서비스 선택 시트
```

## 제안 카드 (Suggestion Card)

입력 시 실시간으로 카드가 표시됩니다:

| 조건 | 카드 | 색상 |
|------|------|------|
| 별칭 매칭 | `🔗 별칭: {keyword}` | 인디고 |
| 연락처 매칭 | `👤 연락처 선택` | 민트 |
| 미인식 텍스트 | `🔍 웹 검색` | 보라 |
| 일정 파싱 | `📅 일정 등록` | 주황 |
| 메시지 파싱 | `💬 메시지 발송` | 초록 |
| 길안내 파싱 | `🚗 길안내 시작` | 파랑 |
| A→B 길안내 | `🚗 길안내 시작` (A → B) | 파랑 |
| 웹검색 파싱 | `🔍 웹 검색` | 보라 |
| 앱 열기 | `📱 앱 열기` | 시안 |

## 파일 구조

| 파일 | 역할 |
|------|------|
| `SmartIntent.swift` | Intent 열거형, SearchType, CommandAlias, AppShortcut 모델 |
| `SmartParser.swift` | 자연어 입력 → SmartIntent 파싱 |
| `ActionManager.swift` | Intent 실행, 설정 CRUD, URL 스킴, CLGeocoder/MKLocalSearch, tel/mailto, SFSafariViewController |
| `OmniViewModel.swift` | UI 상태 관리, 별칭 매칭, 검색 기록, 쿼리 정제, 받아쓰기 |
| `ContentView.swift` | SwiftUI UI (입력, 제안 카드, 숏컷, 설정) |

## 데이터 저장 (UserDefaults)

| 키 | 타입 | 설명 |
|----|------|------|
| `preferredEventCalendarIdentifier` | String? | 선호 캘린더 |
| `preferredReminderListIdentifier` | String? | 선호 미리알림 목록 |
| `defaultSearchEngine` | String? | 기본 검색 엔진 (SearchType.rawValue) |
| `defaultAIService` | String? | 기본 AI 서비스 |
| `searchHistory` | [String] | 최근 검색어 (최대 10개) |
| `commandAliases` | Data (JSON) | 커맨드 별칭 배열 |
| `appShortcuts` | Data (JSON) | 앱 바로가기 배열 |
| `preferAppForSearch` | Bool | 검색엔진 앱 우선 실행 (기본: true) |

## 숏컷 카테고리

| 카테고리 | 버튼 |
|-----------|------|
| 웹검색 | Naver, Google, YouTube, TMDB, AppStore |
| 쇼핑 | 네이버쇼핑, Coupang, AliExpress |
| AI | ChatGPT, Gemini, Claude, Perplexity, Grok |
| 지도 | NaverMap, KakaoMap, KakaoNavi, Tmap, 네이버 경로*, 카카오 경로* |
| 사전 | 영어사전, 국어사전, 한자사전 (인앱 사파리로 열림) |
| 앱열기 | 사용자 등록 앱 + 앱 추가 버튼 |

## 입력 방식

| 방식 | 설명 |
|------|------|
| 키보드 | 직접 타이핑 |
| 클립보드 | 복사된 텍스트 붙여넣기 |
| 받아쓰기 | 마이크 버튼 → `SFSpeechRecognizer` 한국어 음성 인식 |
| X 버튼 | 텍스트 지우기 + 키보드 닫기 (키보드만 활성 시 키보드 닫기) |
