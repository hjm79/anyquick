# 커맨드 별칭 시스템

## 개요

사용자가 직접 등록하는 단축 키워드 → 서비스 매핑.
자연어 파서보다 **먼저** 실행되어, 매칭 시 파서를 건너뛰고 바로 검색.

## 사용 예시

| 별칭 | 서비스 | 입력 | 결과 |
|------|--------|------|------|
| `yt` | YouTube | `yt 강남맛집` | YouTube "강남맛집" 검색 |
| `ㅇㅌ` | YouTube | `ㅇㅌ 뉴진스` | YouTube "뉴진스" 검색 |
| `맛집` | Naver | `맛집 판교` | Naver "판교" 검색 |

## 매칭 규칙

1. 입력 텍스트가 별칭 키워드로 **시작**해야 함
2. 키워드 뒤에 **공백 + 검색어**가 있어야 실행됨
3. 키워드만 입력 시 (검색어 없음) → 별칭 무시, 자연어 파서로 진행
4. 대소문자 무시 (lowercased 비교)

## 데이터 모델

```swift
struct CommandAlias: Codable, Identifiable, Equatable {
    let id: UUID
    var keyword: String       // "yt", "맛집"
    var searchType: String    // SearchType.rawValue ("youtube", "naver")
}
```

## 설정 UI

환경설정 → **커맨드 별칭** 섹션:
- 등록된 별칭 리스트 (키워드 → 서비스명 표시)
- 스와이프로 삭제
- `+ 별칭 추가` → 시트 (키워드 입력 + 서비스 Picker)

선택 가능한 서비스: Naver, Google, YouTube, AppStore, ChatGPT, Gemini, Claude, Perplexity, Grok, 영어사전, 국어사전, 한자사전

## 제안 카드 미리보기

별칭 매칭 시 인디고색 카드로 실시간 표시:
```
🔗 별칭: yt
   강남맛집
   YouTube 검색
```

## 저장

UserDefaults에 JSON으로 저장. 앱 실행 시 `init()`에서 즉시 로딩.
